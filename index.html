Introduction

Coding is sterotypically depicted as something only for nerds or very smart people. However, I am neither nerdy nor very smart. What I am, is somebody fascinated by the freedom offered by computer programming. Anyone can learning coding, including you. However there are so much under the computer programming umbrella that it might be confusing at first. This guide will get you started on your journey of programming.

A good first place to start is to reflect on why you want to learn how to code. For me personally, I just think it is very fun. However, any reason is fine. Then, decide on what language to learn based on what you actually want to do.

Wanna make a website? Start with HTML and CSS (this page was coded using these 2 languages), then gradually move towards Javascript.

Want to learn about AI/Machine Learning? Learn Python.

Want to learn how to make games? Learn GodotScript and Godot.

For anything else, Python is a good spot to start at. There are plenty of resources on Youtube. You may also use AI to your advantage, though coding with AI is very controversial. A good rule of thumb is to understand everything in the AI-generated code if you wish to use it. AI is also a good resource on debugging.

However, these languages are probably not going to be the only languages you will use. A more advanced web developer might use TypeScript with a framework. An experienced Machine Learning enthusiast might prefer C/Rust for performance-critical tasks. A game developer might use C++ for Unreal Engine or C# for Unity.

Personally, I mainly code in C++, but I use other languages too, like C#, Python, or Java. I have gone down my own path in programming, and I hope you take away what you need to go down your own path into the diverse world of programming.
